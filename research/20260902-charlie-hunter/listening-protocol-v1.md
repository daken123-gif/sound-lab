# Charlie Hunter coupling 合成聴取プロトコル v1

## 目的

三つのtone刺激を条件名なしで聴き、次を分離して記録する。

1. 操作の原因を音から追えるか。
2. bass、chord、melodyの役割差を聴き分けられるか。
3. 変化が一括操作ではなく、声部間の空白と受け渡しとして聞こえるか。

これはCharlie Hunterの演奏評価ではない。合成した因果topologyの比較であり、録音、MIDI、採譜、本人の奏法測定を含まない。

## 刺激

- `sample-a.wav`
- `sample-b.wav`
- `sample-c.wav`

各刺激は4.25秒、stereo、22.05 kHz、16 bit。bassは110 Hz、chordは220 Hz、melodyは330 Hzで識別する。1、2、3秒地点に全条件共通の小さな高音markerがある。

## 手順

1. `answer-key.json`を開かない。
2. A、B、Cの順を一巡し、次は逆順で聴く。
3. 各刺激について下表を一度だけ記入する。
4. 記入後にanswer keyを開き、条件名と評価を照合する。
5. 「Hunterらしい」という印象語だけで採否を決めない。

## 記録票

各尺度は1（ほぼ判別不能）から5（明瞭）とする。

| C |  |  |  |  |  |  |

自由記述：

- 一つの操作で全声が同じように動いたと感じた箇所
- 一つの操作で声部が別々に反応したと感じた箇所
- どの声部が消え、どの声部が残ったか
- 音数でなく関係が変わったと感じた箇所
- 不自然、学習不能、作為的に感じた箇所

## 判定境界

- 三刺激が異なることを当てるだけでは、Hunter型couplingの支持にならない。
- `hunter_coupling`条件の評価が高くても、Charlie Hunter本人の演奏再現とは扱わない。
- 原因追跡と役割差が高く、空白／受け渡しが低い場合、couplingは区別できても音楽的関係にはなっていない。
- 固定macroの方が明瞭なら、複雑なcouplingを無条件に優先しない。
- 評価者一人の結果は個人内観測であり、一般化しない。
