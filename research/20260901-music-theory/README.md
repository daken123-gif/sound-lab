## 研究対象と現在の問い

大量の楽曲を解析する前に、何を音楽構造として観測するかを精査する。西洋和声、楽譜、MIDIで測りやすい要素だけを音楽全体とみなさず、Field Looperのリアルタイム演奏設計へ接続できる楽理を作る。

現在の中心課題は、固定ループの再生ではなく、反復の同一性を保ちながら差異を演奏によって生成する仕組みを記述することである。

## 研究範囲

| 層 | 主な対象 | Field Looperへの接続 |
| --- | --- | --- |
| 時間 | パルス、拍節、周期、位相、シンコペーション、ミクロタイミング | タッチの発音・変形時刻 |
| 音高 | 音程、旋法、和声、声部、調性・非調性 | 外れにくさと意外性の制御 |
| 音色 | スペクトル、包絡、質感、混ざり方 | 指の動きを音色演奏へ変換 |
| テクスチャ | 前景・背景、密度、帯域、役割分担 | 複数指による同時分業 |
| 反復 | ループ、オスティナート、変奏、循環 | 垂れ流しにならない反復 |
| 形式 | 蓄積、切断、転換、回帰、消失 | 演奏中の即時的構成 |
| 相互作用 | 応答、模倣、対立、同期、役割交替 | 人間とシステムの即興関係 |
| 身体 | ジェスチャー、触覚、運動記憶、負荷 | マルチタッチ演奏の成立条件 |

## 初期モデル

音符だけでなく、演奏イベントを次の組として扱う。

`E = (t, Δt, p, c, a, r, μ)`

- `t`: 発音位置
- `Δt`: 想定グリッドからの変位
- `p`: 音高関係
- `c`: 音色
- `a`: 強度・包絡
- `r`: 他の音との役割関係
- `μ`: 次の反復で何が変わるか

普通のルーパーが主にイベントを保存して反復するのに対し、本研究では `μ`、すなわち反復時の変化規則まで演奏対象にする。

### 第一命題

> ループとは同じ音列の再生ではなく、同一性を保ちながら差異を生成する周期構造である。

これは現時点の研究仮説であり、確定した設計仕様ではない。

## 観測できた事実

### SoundQuestの体系

- 「自由派音楽理論」はクラシック理論とジャズ理論を単一の正解とせず、ポピュラー音楽の技法を体系へ取り込む立場を明示している。
- 音楽理論の知識を「名前」「効果」「様式」の三層から説明している。
- リズム編は楽譜中心ではなく、ドラム図と音源を用いて、拍、サブディビジョン、アクセント、シンコペーション、クラーヴェ、タイムフィール、ポリリズム、変拍子などを扱う。
- 用語の流派差を認め、独自用語は独自であることを明示する方針を掲げている。
- コード編VI〜VIII章など、一部コンテンツはアカウント登録を要する。
- 利用規約第6条は、サイトおよび関連情報の無断複製、翻訳、改変、転載、公衆送信、配布、出版、営業使用などを禁止している。

### 反復・拍・形式

- flexible ostinato研究では、反復素材が変形し続け、拍・周期・区切りについて複数の解釈を生む構造が扱われている。
- 拍は単独の固定値としてではなく、ドラムパターン、絶対時間、選好されるパルスなど複数の側面から分析できる。
- ドラムパターン、音色、密度、テクスチャの変化は、和声以外の形式形成要因になりうる。
- 標準記譜やピアノロールは発音位置を格子として表しやすい一方、表情的タイミングの連続的な変位を十分に表さない場合がある。

## 推論・仮説

- SoundQuestは、日本語の基礎語彙、旋律、和声、リズムを学ぶ基礎資料として有力である。
- ただし、Field Looperに必要な音色、スペクトル、ミクロタイミング、テクスチャ、反復変異、即興的役割交替、身体インターフェースは別資料で補う必要がある。
- 曲の解析単位を音符とコードだけにすると、Jeff Mills、J Dilla、Autechre、Aphex Twin、ダブなどの重要な構造を取り逃がす可能性が高い。
- SoundQuestの三層は、`名称 → 聴感上の作用 → 様式内での組合せ` という分析順として利用できる。
- ポリリズムは、単純な複数周期の合成によって長い全体周期を作るため、固定ループの複雑化ではない演奏設計へ応用できる。

## Field Looperへ採用する点

- 名前を覚えるだけでなく、操作と聴感上の効果を結びつける。
- 流派ごとの記述を併存させ、単一の正解へ統合しない。
- リズムを拍子記号だけでなく、周期、アクセント、位相、基準拍の保持として扱う。
- 反復素材と基準周期の関係を演奏中に変更できるようにする。
- 音色、密度、無音、ドラムパターンも形式制御として扱う。

## 採用しない点／そのままでは不足する点

- SoundQuestの課程だけを、Field Looperの完全な理論体系とはみなさない。
- 西洋音高体系の用語だけで全ジャンルを解析しない。
- 教材上の説明順を、そのまま機械解析の特徴量順序にしない。
- ポリリズムを整数比の分類だけで完結させず、知覚される基準拍、位相、身体感覚まで調べる。
