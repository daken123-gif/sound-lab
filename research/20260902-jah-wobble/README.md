# Jah Wobble研究

- 状態: `active`
- research-id: `20260902-jah-wobble`
- 更新日時: 2026-09-04 UTC
- 研究対象: Jah Wobbleのベース演奏、反復、Dub、即興、録音方法
- 現在の問い: 録音済みループの同一再生ではなく、少数の音を身体で反復しながら毎周更新する演奏を、Sound Labのマルチタッチ楽器へどう変換できるか

## 研究上の位置

この記録はJah Wobbleの人物・演奏・制作方法を継続的に調べる研究正本である。Sound Labへの製品採用、UI決定、DSP実装を意味しない。

中心に置くのは「太いDubベース」という音色模倣ではない。次の区別を研究する。

- 録音済み波形が同一周期を再生する固定ループ
- 演奏者が周期を保持しながら毎周を再発音する反復
- 録音済み素材の存在、不在、帰還をその場で組み替えるDub演奏
- 中心音を保持しながら他奏者との関係で内部を変える集団即興

## 観測できた事実

### 1. 本人はDubを固定された様式として捉えていない

InnerviewsでWobbleは、後年のDubが画一的で怠惰になり、初めてKing Tubbyを聴いたときに感じた解放や革命性を失ったと批判している。一方、初期Dubについては、空虚、相互依存、恒常的な流動を示すものとして語る。

ここから確認できるのは、WobbleにとってDubが特定のエフェクト設定やジャンル記号ではなく、音と関係が固定されず動き続ける方法だということである。

### 2. ベースの基本単位は少音数・低域・モード・リズムである

同じインタビューで本人は、自分の方法を次のように説明している。

- heavyでmodalなベース
- 音数は多くない
- 速いラインであってもrhythmicかつdubby
- low bottom endを持つ
- 西洋の長短調による機能和声より、modal / pentatonicなblock unitとして扱う

本人はこの方法が中国、韓国、アラブ等の音楽と接続しやすい理由も、相手が使うmodeと音群をまず学び、そこへリズムと旋律を結合した低域を置けることに求めている。

### 3. 即興で事前ループを準備することを明示的に退けた

Bill Laswellと`Realm of Spells`を制作した際、参加者が即興用のloopsを準備しようとしたのに対し、Wobbleは事前に何も用意せず、その瞬間に演奏することを求めたと説明している。

これは反復の否定ではない。Wobble自身の音楽には持続するpatternがある。ここで退けられたのは、演奏開始前に固定された時間構造へ即興を従属させることである。

### 4. Fender Precisionは本人の作曲運動を変える

本人は、Fender Precisionへ戻るとPiL期のような演奏になり、オクターヴ、半音階的な動き、単純でnaiveだがgrooveを持つlineが自然に出ると説明している。別の時期にはOvation Magnumを使用し、近年の長時間演奏ではflatwoundやnylon弦も用いている。

ここで確認できるのは、楽器が既に決まったフレーズを受け取る透明な入力装置ではなく、演奏者が選ぶ音程、運動、音価を誘発するということである。

### 5. Jaki Liebezeitとの演奏は低音とドラムの相互形成だった

Wobbleは`Full Circle`期のJaki Liebezeitを、自分が共演した最良のドラマーと評価し、master musicianとの演奏ではdrumsがbassへ大きく影響すると述べている。両者は譜面上の合意より、演奏しながら自然に関係を形成した。

Holger Czukayから受け取った原則として、Wobbleは「先に演奏し、後で考える」ことを挙げる。ただし本人はこれを自己陶酔的なjamと同一視せず、明晰な状態から音楽が増殖する過程として説明している。

### 6. 録音は分離度よりtextureとvibeを優先しうる

`Full Circle`について本人は、Inner Spaceのlive roomとcontrol roomが分離されていないことによる音の漏れを当初気にした一方、Canの重要な録音はtextureとvibeを中心に成立していたと振り返る。

Holger Czukayの編集については、四分の一インチテープを通常の音楽編集より映画編集のように扱ったこと、テープ速度を落として別の音域・質感のギターを作ったことを本人が説明している。

### 7. 二人のベーシストは音域と役割をその場で譲り合う

`Realm of Spells`でBill Laswellと共演した際、Wobbleは二人が同じregisterへ同時に入らないことを基本条件として挙げる。一方が低域へ行けば、もう一方は数octave上へ移る。固定分担ではなく、相手の現在位置に応じた`either / and / or`の判断が続く。

### 8. `Metal Box`再構築は原曲の保存ではなく再演だった

Wobbleは2018年にFender Precisionを再び弾いたことを契機に、PiL期のbass lineと`Metal Box`を現在ならどう構成するか考え始めた。2020年に`Metal Box`再録の提案を受け、遠隔制作を開始した。

本人の説明では、`Poptones`と`Albatross`は主部分で転調せず中心部へ留まる。`Socialist`には新しいmodulationと旋律を加え、`The Suit`には原版になかったguitarを加えた。2021年の`Metal Box - Rebuilt In Dub`は原曲の忠実な保存ではなく、当時未完だった可能性を現在の演奏で再び開いた記録である。

## 現在の分析

### 反復されるのは音声ではなく、責任である

Wobbleの反復を「ループ」とだけ呼ぶと、異なる二つの状態が混ざる。

```text
固定ループ:
  前周期の録音結果 -> 現周期へ同一再生

Wobble型反復:
  周期の骨格 -> 演奏者が現周期を再発音 -> 他者の応答を受ける -> 次周期を再決定
```

両者とも周期性を持つ。しかし後者では、音価、attack、mute、音域、他者との前後関係を維持・変更する責任が演奏者から消えない。

この研究では、この差を暫定的に「再生される周期」と「再演される周期」と呼ぶ。これは分析語であり、Wobble本人の用語ではない。

### 低音は声部ではなく重力場を作る

Wobbleの少音数・modal・low bottomという本人説明から、低音の役割を単旋律の正確さだけで評価しない。

中心音を長く保持することで、他の音が次のいずれに聞こえるかが変わる。

- 中心へ帰る音
- 中心から離れる音
- 半音で摩擦する音
- octaveで身体を拡張する音
- rhythmとして中心を切り刻む音

したがって一音の情報量は、pitch classの数ではなく、中心音に対する時間的関係で増える。

### `Poptones`仮説: 周期内部の運動

本人は`Poptones`を、Aを中心に主部が転調せず留まる構成として説明している。またFender Precisionがoctaveとchromatic movementを誘発すると語る。

ここから、`Poptones`研究では次を測る必要がある。

- 中心音とoctaveの出現位置
- chromatic approachの方向
- 各音の長さ
- drum onsetとの相対位置
- 周期ごとの省略と追加

現段階で「毎周異なる」と断定しない。差の大きさと規則性は音源解析で検証する。

### `Albatross`仮説: 中心保持と環境変化

本人は`Albatross`をE minorを中心に転調せず留まる構成として説明している。この曲ではbass lineそのものの変化だけでなく、周囲の密度、guitar、drum、残響、欠落が中心音の意味を変える可能性がある。

分析ではbassだけを切り出して完結させず、同じbass eventが周囲の編成変化でどう再文脈化されるかを調べる。

### Jaki Liebezeit接続: 機械的精度ではなく相互拘束

JakiとWobbleの関係を「正確なdrumの上でbassが自由に弾く」と捉えない。

- drumがbassの発音と音価を変える
- bassがdrumのどの層を前景化するか変える
- 両者は周期を壊さず、周期内部の重心を動かす
- 自由は共通時間から離脱することではなく、共通時間の内部で相手に応答することにある

この仮説はCAN、Jaki Liebezeit、Holger Czukay研究と接続する必要がある。

### Dub接続: 空白は結果でなく入力である

既存のDub演奏文法研究では、`CUT`、`THROW`、`REVEAL`、`VACUUM`、`TAIL CHOKE`等を、録音済み素材の存在と帰還を演奏する操作として整理している。

Wobble研究は、そのDub操作の前段へ次を加える。

- 低域の中心自体を人間が現在演奏している
- 中心が残るから、他声部のCUTが空間変化として知覚される
- bassまで消す判断は、単なるmuteではなく重力の消失になる
- returnは固定lineの代用品ではなく、生演奏と衝突する過去になる

## Charlie Hunter研究との比較

両者とも少人数または一人の身体から複数の役割を発生させるが、中心は異なる。

| 軸 | Jah Wobble | Charlie Hunter |
| --- | --- | --- |
| 身体の中心 | 一つの低域lineを現在へ保持する | 低音と上声を同一身体で同時保持する |
| 周期の生成 | 毎周を再発音し、他者へ応答する | 声部間関係を同じ手の制約内で変える |
| 主な音程運動 | 中心音、octave、chromatic approach、mode | 低音、和声、旋律の拘束された対位法 |
| 休符の意味 | 低域の重力または周囲の空間を開閉する | 声部間の実行可能性とpocketを調整する |
| 楽器設計への示唆 | 一指で中心を保持しながら再発音責任を残す | 複数声部を別生成器へ分解しすぎない |

両研究を統合すると、Sound Labは「一人で多人数分を自動生成する装置」ではなく、一つの身体が複数の音楽的責任を持ち続けられる楽器として設計する必要がある。

## Sound Labへの候補

以下は研究候補であり、採用済み仕様ではない。

### 1. CENTER HOLD

一指でmodal centerを保持する。ただし接触中に完全な定常droneを自動再生しない。

候補操作:

- 接触圧または面積: saturation / damping
- 接触位置の微動: 倍音重心
- 再tap: 新しいattackと周期の再決定
- 離す速度: muteの硬さとtail送出

iPhoneが圧力を安定取得できるとは限らないため、接触面積、移動速度、保持時間を含めて実機検証する。

### 2. OCTAVE RELATION

第二指を別鍵盤として扱わず、CENTER HOLDとの距離でoctave、fifth、chromatic approachを選ぶ。

重要なのは自動arpeggioではない。二指間の関係を演奏者が変えた瞬間だけ、新しい音程事件が生じることにある。

### 3. CYCLE TRACE

直前周期のaudioを再生する代わりに、発音位置、音価、mute、強度を減衰する軌跡として提示する。演奏者は軌跡を参照しながら次周期を弾き直す。

候補状態:

```text
CycleTraceEvent = {
  phase,
  duration,
  intensity,
  register,
  age
}
```

軌跡は演奏補助であり、自動quantize、自動補完、音声再生を行わない。

### 4. LIVE GRAVITY / DUB FIELD

生演奏の低域と、既存Dub研究のshared tailを分離する。

```text
live bass gesture -> dry gravity ----------------------+
                  -> explicit throw -> shared tail ----+-> output
other live/raw sources -> cut/reveal/throw -------------+
```

低域を保持したまま周囲だけを消す場合と、低域自体を消して空間の重力を失わせる場合を別gestureにする。

### 5. REGISTER NEGOTIATION

二つの低音的役割が共存するとき、一方を自動的に消去しない。衝突を可視化し、演奏者が次のいずれかを選ぶ。

- 一方を数octave上へ移す
- 一方のlow bandを削る
- 発音時刻をずらす
- 交互に前景化する
- 敢えて衝突を残す

Laswellとの二bass編成から得るのは自動voice allocationではなく、音域交渉を即時操作にする発想である。

## 採用しない／まだ採用しない

- Jah Wobble風bass lineの自動生成。
- `Poptones`等のbass phraseをpreset loopとして搭載すること。
- 一般的なsub-bass boostをWobble研究の実装と呼ぶこと。
- roundwound / flatwoundのEQ presetだけで奏法差を代替すること。
- Dub風delayとreverbを常時master insertへ置くこと。
- 直前周期を自動再生し、演奏者の再発音責任を消すこと。
- ランダムなtiming揺らぎを「人間らしさ」として加えること。
- 本研究だけを根拠に既存の4トラック構成や主演奏面を変更すること。

## 失効した判断
