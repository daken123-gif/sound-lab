## 目的

鎮座DOPENESSのリリックを、ソロ名義だけへ縮めず、ユニット、客演、共作、提供詞、CM・委託制作、別ヴァージョン、公開フリースタイル、MCバトルまで含む生きた母集団として研究する。

「全て」は、単一の配信サービスに現在表示される曲だけを意味しない。初期CD-R、廃盤、無料配信、アナログ限定、映像内即興、他者名義の客演も探索対象に残す。

## 保存境界

著作権のある歌詞本文はGitへ複製しない。代わりに、曲名、名義、年、収録作、作詞・歌唱上の役割、固定詞／即興／別版の区分、出典URL、非代替的な研究注釈を保存する。

これは対象曲の削除ではない。各曲を台帳に保持し、権利者または許諾を受けた歌詞掲載ページへ戻れるようにする。ユーザーが権利を持つ本文、明示的に提供した本文、パブリックドメイン資料は、由来を確認して別管理する。

## 現在の母集団

確認済み・発見済みを合わせると、題名を持つ歌入り音源／リリック・ファミリーは暫定下限180件超。ただしこれは「鎮座DOPENESSが単独で全詞を書いた曲数」ではない。共同名義、客演、カバー、他者詞の歌唱を含む研究対象数である。

公開即興はこの数へ混ぜない。大会バトルは資料上24試合を確認したが、ライブ断片、再投稿、セッション、CM内即興は母集団が閉じていない。

## 分類法

| code | 区分 | 判定基準 |
| --- | --- | --- |
| `FIXED` | 固定スタジオ詞 | 正式録音として反復可能な詞 |
| `VERSION` | 別版・改詞 | 文言、配役、終端、演奏条件が異なる |
| `DECLARED_FREE` | 明示された即興 | 作品名または公式説明でfreestyleとされる |
| `BATTLE_RESPONSE` | バトル応答 | 相手・観客・直前発話への応答を中心に生成 |
| `HYBRID` | 準備詞と即興の混成 | 準備した詞を捨て即興した場合など |
| `OTHER_WRITER_PERFORMANCE` | 他者詞の歌唱・演出 | 鎮座が歌唱等を担うが作詞者は別 |
| `COMMISSIONED_MICRO` | CM・委託短篇 | 広告、番組、ブランド映像等の短い詞・語り |
| `ATTRIBUTION_OPEN` | パート帰属未確定 | 共同クレジットしかなく行単位帰属を断定できない |

## 現在の中核判断

1. 韻は意味を飾るだけでなく、次の語、場面、役割を発生させる因果として働く。
2. 音の連鎖は無制限ではなく、身体、具体的場面、共演者、観客によって着地させられる。
3. 話者は固定した自伝的人格ではなく、ラッパー、労働者、犬、酔客、寝坊した会社員などへ切り替わる。
4. 食欲、排泄、睡眠、発汗、入浴などの身体が、大言壮語や抽象論を生活の尺度へ戻す。
5. 喜劇的な自己失墜は真剣さを否定しない。誇大化を防いだまま本気を運ぶ。
6. 反復は強調だけでなく、語義を増殖させ、抜け出せない状態を実演する。
7. 固定詞と即興は二分できない。改詞、別版、準備詞を捨てた即興、共同生成がある。
8. 近年は「音が意味を生む」機構に加え、親子、祖父母、仲間、仕事の経路など「接続が自己を生む」主題が強まる。

## 事実・推論の境界

- 曲目、発売日、クレジットは公式レーベル、公式アーティスト、権利処理された歌詞サービスを優先する。
- Wikipediaは探索入口としてのみ使用し、単独では作詞帰属を確定しない。
- 曲単位でFNCY作詞とある場合、鎮座の行単位パートを自動推定しない。
- タイトルが同じでも同一歌詞、同一テイク、同一マスターとは判定しない。
- 未取得音源の内容をタイトルや近接作品から補わない。

## Field Looperへの採否

現時点ではリリック研究段階であり、Field Looperへの実装採用は未決定。鎮座の表層語彙を模倣する用途にはまだ使わない。

## 失効した判断

- 「配信カタログを見れば全作品が得られる」: 失効。CD-R、無料配信、アナログ限定、CM、即興が落ちる。
- 「固定詞か即興かの二分類で十分」: 失効。改詞、別版、準備詞を捨てた即興、共同生成がある。
- 「曲クレジットから鎮座の全行を特定できる」: 失効。共同名義では行単位確認が必要。
