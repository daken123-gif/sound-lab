## 注釈項目

- event / date / venue
- source uploader / original or reupload
- performers / order
- beat source / BPM変化 / 拍節
- prepared / improvised / unknown
- direct response target
- audience response
- repeated fixed phrases
- later studio reuse
- visible edits / cuts
- transcription availability and rights status

## 暫定仮説

通常曲の「身体による着地」に対し、バトルでは「相手と会場による着地」が強くなる。全24試合のテイク比較前なので確定判断にはしない。
