# Conny Plank研究 — 録音・ミックスを演奏にする

- research-id: `20260831-conny-plank`
- 状態: `active`
- 更新日時: 2026-09-03
- 研究対象: Konrad “Conny” Plank（1940–1987）の録音思想、制作手法、ミックス操作
- 現在の問い: 反復素材を垂れ流さず、録音・時間・位相・空間をリアルタイム演奏にするため、Plankの仕事から何を抽出できるか
- 触る実装パス: なし（研究記録のみ）
- 依存する研究: `20260828-kaoss-master-fx`、Skulptur研究（本文はGit未確認）、Dedalus／Microcosm研究（本文はGit未確認）

## 先に置く結論

Conny Plankから採るべきものは、特定のヴィンテージ機材の音色ではない。

採るべきなのは次の制作構造である。

1. 録音を完成演奏の保存ではなく、音楽が発生する場にする。
2. テープ速度、位相、反転、編集、エコー、パンを、ミックス時の一回的な身体演奏にする。
3. 一つのジェスチャーで複数パラメータを動かすのではなく、一つの知覚可能な音響行為を起こす。
4. 反復を完成済み伴奏として固定せず、現在の演奏との差が聞こえる基準面として使う。
5. 技術で奏者の固有性を均質化せず、各奏者の身体的・音響的な差を増幅する。

本研究ではこれを仮に **performed signal path（演奏される信号経路）** と呼ぶ。これは製品名でも確定仕様でもない。

## 一次証言・近接資料

### 1. プロデューサーの仕事

Abletonのスタジオ史記事は、Plankの発言として、プロデューサーの役割は技術操作以前に「恐れや遠慮のない雰囲気」を作り、無垢な瞬間を正しい時に捕まえることだと紹介している。またPlankは、シンセサイザーを既存楽器の模倣として、ドラムマシンを生ドラマーの模倣として使うことを否定している。

- 資料: [A Brief History of The Studio As An Instrument: Part 3 — Ableton](https://www.ableton.com/fr/blog/studio-as-an-instrument-part-3/)
- 証拠境界: Plank本人の録音音声ではなく、記事内の引用である。

### 2. NEU!第1作の制作条件

Michael Rotherは、NEU!第1作について次を証言している。

- 録音は8トラック。
- 録音に4日、別スタジオでのミックスに約1週間。
- RotherとKlaus Dingerは、録音前に二人で曲を演奏・完成させていなかった。
- 基本トラックを録り、その場で互いの音へ反応しながらオーバーダブした。
- Rotherはこの方法をaction paintingにたとえている。
- 制作時間の不足は問題だった一方、判断を終わらせる圧力として働いた。

- 資料: [Michael Rother — Red Bull Music Academy Tokyo 2014](https://www.redbullmusicacademy.com/lectures/michael-rother-tokyo-2014/)

ここから確認できるのは、Plankが偶然性だけを賛美したのではなく、短時間に起きた素材を記憶し、選び、結論へ持っていく役割を担ったことである。

### 3. 手動フェイジング

Rotherによれば、`Negativland`では同一ミックスを2台のテープマシンで再生し、Plankが一方の機械へ手を触れて速度差を作り、耳で判断して離すことで手動フェイジングを行った。Rotherは、加工によって直進するベースとドラムの上に、上下する塵の雲のような音響が生まれたと説明している。

- 資料: [NEU! — Life of the Record: Notes and Transcript](https://lifeoftherecord.com/neu-notes)

ここで重要なのは「フェイザーを使用した」ことではない。位相差の発生、拡大、復帰がPlankの手と判断に従い、同じ軌跡を自動反復しないことである。

### 4. 逆回転を応答相手にする

Rotherは、`Hallogallo`制作中にPlankがテープを裏返し、既存演奏を逆回転させたことで、新しい旋律を追加する刺激が生まれたと証言している。

これは完成したギターを「逆再生エフェクト」で装飾しただけではない。変換後の音を奏者へ返し、その返答として次の演奏が発生している。

- 資料: [Michael Rother — Red Bull Music Academy Tokyo 2014](https://www.redbullmusicacademy.com/lectures/michael-rother-tokyo-2014/)

### 5. カスタム卓

Michael ZählはPlankのスタジオ用メイン・コンソールの設計者であり、Zähl公式サイトもその来歴を確認している。

- 資料: [Zähl Elektronik-Tontechnik — About](https://zaehl.com/about)

PlankのアシスタントPetrus Wippelの証言を紹介するFriezeの記事によれば、Plankは信号経路を組み替え、一つの指で左右パンとdry/wetを同時に動かし、ミックス中に音を時間・空間内で飛ばせるようにしていた。

- 資料: [Music — Frieze](https://www.frieze.com/article/music-18)
- 証拠境界: コンソールの全回路図を取得したわけではなく、助手の証言を経由した記述である。

### 6. 固定された「Plank音」ではない

Plankの息子Stephan Plank、John Foxx、Dave Hutchinsらの証言を含む記事では、農家を改装したスタジオの不均一な木・漆喰壁、機材を製作・改造する工房、複数の音楽家が出入りする制作環境が記録されている。Foxxは、Plankが均質に吸音された空間より自然で現実的な響きを求めていたと回想する。

- 資料: [Conny Plank — Electronic Sound](https://www.electronicsound.co.uk/features/long-reads/conny-plank/)

ただし、これは「自然な録音だけを好んだ」という意味ではない。Duke Ellingtonの比較的素直な録音と、NEU!の強いテープ処理が同じ人物から出ている。素材に応じて介入量を変える点が重要である。

## 「ループ」とPlank的方法の違い

ユーザーが拒否しているのは、反復そのものではなく、完成済み反復を再生するだけの行為をライブ演奏として代用することである。

Plank周辺の反復は、次の点で異なる。

| 完成ループの再生 | Plank的方法 |
| --- | --- |
| 反復単位が完成品 | 反復は現在の変化を知覚する基準 |
| 再生開始が主な演奏 | 再生中の位相、密度、空間、編集判断が演奏 |
| 周期ごとの差が不要 | 周期ごとの差が音楽の中心 |
| エフェクトは装飾 | エフェクト操作が次の演奏を誘発 |
| 元素材と処理結果が一方向 | 処理結果が奏者へ戻り、新しい入力を生む |

したがって、本プロジェクトで反復を残すなら、最低でも次のいずれかを現在演奏へ戻さなければならない。

- 周期内の発音選択
- 位相差の生成と復帰
- 再生方向
- 読取位置
- 音像の距離・残響
- 入力と過去音の応答関係

単なる再生音量の上げ下げでは不足する。

## 設計候補: Plank gesture engine

以下は研究から導いた仮説であり、製品採用・実装済みではない。

### A. 手動位相差

同じ素材を二つの読取ヘッドへ送る。

- 1本目は基準速度を維持する。
- 2本目は指の移動速度に応じて微小に加速・減速する。
- 二本指の距離が時間差を表す。
- 指を近づけると位相が再結合する。
- 指を離した瞬間の速度で復帰時間が決まる。

通常のLFOフェイザーと異なり、周期運動を自動生成しない。一回の指運動が一回の位相軌道を作る。

### B. 空間投擲

単純な `x = pan`、`y = reverb` を避け、ジェスチャーを知覚可能な因果へ束ねる。

例として、音を右奥へ投げる一動作なら次を連動させる。

- dry音は右へ移動する。
- 初期反射は元位置付近へ残る。
- 距離に応じて高域と直接音が減衰する。
- delay returnは移動方向と反対側へ残る。
- 指を離した後はtailだけが慣性を持つ。

これはKAOSS型Masterの復活ではない。固定された二軸エフェクト面ではなく、録音素材に対する一時的な空間行為としてSkulptur型主演奏面の候補部品に限定する。

### C. 変換音への返答

逆再生や減速を最終結果として鳴らすだけでなく、その音を聞きながら次の入力を録れる構造にする。

```text
現在入力
  -> 短時間メモリ
  -> 手動変換
  -> 即時モニター
  -> 奏者の返答
  -> 新しい現在入力
```

変換は一方向のエフェクトではなく、次の演奏を生む相手になる。

### D. 捕捉は明示操作、保持は循環バッファ

`integration/DIRECTION.md`の「録音開始は人間が決める」を維持する。

- 入力は短い循環バッファで一時保持する。
- バッファ保持だけでは録音状態にしない。
- ユーザーの明示操作で直前区間を採取する。
- 採取後もRAWを保持し、変換は非破壊とする。

これは自動録音ではない。過去数秒を選べる明示録音である。UI上では常時監視と保存済み状態を混同させない表示が必要になる。

### E. 制約を演奏密度へ変える

NEU!第1作の短い制作時間をそのまま模倣する必要はない。しかし、無限undo、無限take、無限layerが判断を遅らせる問題は現在のアプリでも残る。

候補:

- 演奏中のgesture takeを一本だけ前面化する。
- 新しいtakeを始めてもRAWは消さない。
- 「最善版の自動選択」は行わない。
- 演奏後にパラメータを細かく修正して完成させることを主演奏経路にしない。

## 採用候補

現段階で研究から強く支持できる候補:

1. **処理結果を次の入力へ返す循環**
2. **LFOではなく手で作る一回的な位相軌道**
3. **一つのジェスチャーを一つの空間行為として設計すること**
4. **反復を変化の基準面として使うこと**
5. **少数の素材へ深く触ること**
6. **電子音・人力音の差を消さないこと**
7. **明示録音と短時間の過去採取を両立すること**

## 採用しない点

1. Plank作品に似せた固定EQ、固定サチュレーション、固定テープノイズ。
2. `krautrock`、`motorik`という名称だけから作るジャンルプリセット。
3. ヴィンテージ卓の外観模倣。
4. 自動生成された「偶然」をPlank的即興と呼ぶこと。
5. エフェクトの派手さだけを取り出したKAOSS型Masterの復活。
6. Plankが関与したという理由だけで全作品を同じ制作原理へ還元すること。

## CANとの境界

Conny Plankを「CANの主要録音エンジニア」と扱わない。CANの中心的作品は、バンド自身のInner Space環境とHolger Czukayらの録音・編集によって成立している。PlankはCANの一部メンバー、周辺作品、一部クレジットと接続するが、NEU!、Cluster、初期Kraftwerkにおける位置と同一ではない。

この境界は、Plank研究とHolger Czukay研究を混ぜないために保持する。

## 推論・仮説

### H-01: 非ループ楽器ではなく、ループを未完了のまま保つ楽器

問題はループ機能の有無ではない。ループが演奏前に完成し、以後の判断を不要にすることが問題である。

本プロジェクトでは、各反復周期に演奏者が介入できる余地を残すことで、ループを未完了状態に保てる可能性がある。

### H-02: マルチタッチの価値は同時パラメータ数ではなく、相互関係

十本の指へ十個のノブを割り当ててもPlank的にはならない。二つの読取ヘッドの距離、現在音と過去音の比率、直接音と残響の離れ方など、指同士の関係を音響関係へ写す必要がある。

### H-03: Performance Takeは音声だけでなく判断軌跡を保存する

同じ音源を同じプリセットへ通しても、いつ触れ、いつ離し、どの速度で位相を戻したかが演奏の固有部分になる。Contact Performance Take候補は、この判断軌跡を同じgesture frame列から再生できる場合にのみPlank的方法と接続できる。

## 技術展開: 手動テープ・フェイジングを演奏へ移す

以下はPlankの回路を復元したものではない。Michael Rotherの証言で確認できた「二台のテープマシンの一方へ手を触れ、速度差を作って戻す」という行為を、デジタル信号処理へ翻訳する設計仮説である。

### 1. 最小モデル

入力を \(x[n]\)、時間変化する遅延量を \(D[n]\)、処理音の混合量を \(g\) とすると、基本形は次になる。

\[
y[n] = (1-g)x[n] + g\,x[n-D[n]]
\]

遅延コピーと原音の加算により、周波数応答には櫛状の山谷が生まれる。\(D[n]\) が連続的に変わると、その山谷も移動する。

一般的なフランジャーは \(D[n]\) を正弦波・三角波LFOで周期変調する。Plank型候補では、LFOを置かず、接触速度から遅延量を積分する。

\[
D[n+1] = \operatorname{clip}(D[n] + u[n], D_{min}, D_{max})
\]

ここで \(u[n]\) は指が直接指定する遅延量ではなく、二台目の仮想テープ速度と基準速度との差である。

- \(u[n] > 0\): 読取位置が遅れ、遅延量が蓄積する。
- \(u[n] < 0\): 読取位置が追いつき、遅延量が減る。
- \(u[n] = 0\): 現在の時間差を保つ。
- \(D[n] = 0\): 二つの読取位置が再結合する。

資料:

- [Flanging — Physical Audio Signal Processing](https://www.dsprelated.com/freebooks/pasp/Flanging.html)
- [MSP Delay Tutorial 4: Flanging — Cycling ’74](https://docs.cycling74.com/learn/articles/15_delaychapter04/)

### 2. 「位置を動かす」のではなく「速度差を作る」

画面座標をそのままdelay timeへ割り当てると、指の小さな震えが遅延ジャンプになり、音程飛びやクリックを起こしやすい。また、二点間を往復するだけのXYエフェクトへ戻る。

Plankの行為から採るなら、接触変位は速度差 \(u[n]\) へ写す。

候補写像:

\[
u[n] = u_{max}\,\tanh(k\,\Delta p[n])
\]

- \(\Delta p[n]\): 基準指と操作指の相対移動量、または操作指の速度。
- \(k\): 小動作域の感度。
- \(u_{max}\): 最大速度差。
- \(\tanh\): 端で急激に暴走させず、中央では細かく扱うための候補。

これにより、同じ位置へ触れても、そこへ到達した運動が違えば異なる位相軌道になる。画面上の場所が音色プリセットを意味するのではなく、身体運動の履歴が音を決める。

### 3. fractional delay

\(D[n]\) は整数サンプルに限定できない。整数へ丸めると遅延位置が段階的に飛び、操作音とは別のzipper noiseを生む。

最低限、隣接サンプル間を補間するfractional delayが必要になる。

- 線形補間: 軽いが、高域の振幅誤差が増える。
- 三次補間: 計算量は増えるが、移動時の連続性を改善できる候補。
- all-pass補間: 振幅を保ちやすい一方、位相誤差を持つため、dryとの加算結果を聴感検証する必要がある。
- oversampling: 急な時間変調で生じるaliasingを抑える候補だが、iPhoneの負荷測定前に固定しない。

資料:

- [Fractional Delay Filtering by Linear Interpolation — Physical Audio Signal Processing](https://www.dsprelated.com/freebooks/pasp/Fractional_Delay_Filtering_Linear.html)
- [Fractional Delay using Linear Interpolation — Tamara Smyth](https://musicweb.ucsd.edu/~trsmyth/filtersDelayII/Fractional_Delay_using.html)

### 4. LFOフェイザーとの構造差

| 一般的なLFO flanger | Plank型候補 |
| --- | --- |
| 周期は装置が生成する | 軌道は毎回の指運動が生成する |
| rate/depthを設定する | 加速、減速、静止、復帰を演奏する |
| 開始後も自動的に変化する | 接触がなければ新しい軌道を作らない |
| 同じ設定なら同じ周期へ戻る | 同じ位置でも運動履歴により結果が変わる |
| 効果の周期が拍と競合しうる | 奏者が拍の内部・外部へ任意に置ける |
| LFO位相は通常記録対象でない | 指の時間軌跡そのものをPerformance Takeへ残す |

ここで「自動変化を一切禁止する」とは決めない。Plank型の固有部分は、変化の開始、方向、滞在、再結合を人間が引き受ける点にある。

### 5. 二指状態機械

指の本数を機能数として数えず、二本の関係で二台の仮想テープを作る。

| 状態 | 入力 | 音響状態 |
| --- | --- | --- |
| ALIGNED | 未接触 | \(D=0\)。処理音を前面化しない |
| ENGAGE | 第一指が接触 | 対象素材と基準位置を固定。wetを短く立ち上げる |
| DIVERGE | 第二指が基準から移動 | 相対運動を速度差へ変換し、\(D\)を蓄積 |
| HOLD | 二指関係が静止 | 速度差を0へ近づけ、蓄積した\(D\)を維持 |
| REVERSE_CATCHUP | 第二指が反対方向へ移動 | 読取ヘッドが追いつき、\(D\)が0へ近づく |
| REJOIN | 指を離す、または二指が合流 | 不連続に0へ飛ばさず、制限速度で再結合 |
| TAIL | 再結合後 | 残響・feedbackだけを残し、原音経路へ戻る |

REJOINが重要である。指を離した瞬間にdelayを0へ設定するとクリックや不自然な音程飛びになる。離す動作はエフェクト終了命令ではなく、二台の仮想テープをどう追いつかせるかという最後の演奏になる。

### 6. 三本目以降

三本目以降を必須モディファイアにしない。基本行為は二指で完結させる。

追加接触を使う場合も、既存指の意味を書き換えず、別の関係を重ねる。

- 第三指: 位相差のある音だけを空間へ送る量。
- 第四指: feedbackの開閉。触れている間だけ戻す。
- 別トラック上の接触: 対象素材を増やすのではなく、同じ位相軌道へ一時的に参加させる。

これは固定仕様ではない。iPhone実機で誤接触、到達距離、同時操作の視認性を検証するまで、三本目以降の割当は採用しない。

### 7. 安全境界

- feedbackは内部で上限を持たせるが、UI上の操作感を勝手に圧縮しない。
- wet/dryの加算でピークが増えるため、試作比較では同一ラウドネス条件を別途用意する。
- モノラル入力でも位相キャンセルが起こる。モノ互換性を「音が出た」だけで合格にしない。
- 可変遅延の補間歪みと、狙ったテープ的な揺れを区別して記録する。
- CPU不足によるdropoutを音響的偶然として採用しない。
