# DemucsをMacで動かす
状態: スクリプトの構文確認済み。Mac実機での導入・分離は未検証。
このチャットの実行環境では通信ポリシーによって依存取得が停止し、分離未実行。

## 初回
Python 3.11とffmpegが必要。Macのターミナルでこのフォルダを開き、実行する。

```bash
bash setup-mac.sh
```

PyPIの無料OSS（Demucs 4.0.1、PyTorch/Torchaudio 2.2.2、NumPy 1.26.4等）と
Metaのhtdemucsモデルを取得する。登録・APIキー・従量課金は不要。
通信先はpipの設定に従うパッケージ配布元と、モデル配布元dl.fbaipublicfiles.com。
モデル取得には音源を使わない。ローカルモデル再読込に成功したときだけ導入完了とする。
依存の完全固定ではない。実際に解決した版はinstalled-versions.txtへ記録する。
Pythonやffmpegの自動インストール、環境の通信制限の変更はしない。

## 分離
```bash
bash run.sh "/絶対パス/音源.wav" "/絶対パス/新しい出力"
```

CPUでdrums / bass / other / vocalsの4つのWAVを出力する。
ローカルモデルを明示指定するため、分離時にモデルをダウンロードしない。
既存出力は上書きしない。速度優先でshifts=0、品質は未評価。
まず必要な短区間を使う。区間の元音源内開始時刻を必ず残す。

## 採譜につなぐ
隣のbasic-pitchキットでbass.wavやother.wavを解析できる。
分離区間が元音源の620秒からなら、Basic Pitchの区間内時刻に620秒を加える。
分離の漏れ・混入や倍音の誤検出があるため、ノートは候補として扱う。
原音との照合、手動正解との比較を行うまで採譜精度の改善とは言えない。

このフォルダを他のMacでも取得して使える。iPhone単体でPythonを実行するものではない。
音源・分離音・モデル・仮想環境はGitに追加しない。
