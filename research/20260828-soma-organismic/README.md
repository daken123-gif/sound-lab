## 観測できた事実

### 1. 5機種は別々の層を担当している

| 機種 | 主な層 | 公式資料から確認できた中心構造 |
|---|---|---|
| TERRA | 演奏入力と音源 | 12ノートセンサー、4音色センサー、4移調センサー、2ホールド、三軸モーション、32音響アルゴリズム |
| FLUX | 空間ジェスチャー | 二本の磁気弓、多極磁気センサー、位置と角度による最大16系統の連続制御 |
| LYRA-8 | 発音と非線形帰還 | 8音源、ペア／群の樹状構造、FM、HYPER LFO、二重クロスフィードバック・ディレイ、後段歪み |
| PULSAR-23 | リズムと制御信号 | 4ドラム音源、4イベントルーパー、クロック分周、SHAOS、CV/MIDI/身体導電、CV制御FX |
| COSMOS | 音声記憶と時間 | 44.7秒の音声記憶、互いに異なる素数長の遅延線、非同期LFO、低速カオス変調 |

### 2. TERRA

TERRAの鍵盤は12個のノートセンサーを持ち、ベロシティと圧力を扱う。圧力によって遅い立ち上がりやビブラートを手で作れる。ほかに4個の動的音色センサー、4個の移調センサー、2個のホールドセンサー、内部の三軸モーションセンサーがある。

移調センサーは組合せによって16種類の移調状態を作る。32個の音響アルゴリズムは、パラメーターを一から組み立てる素材ではなく、それぞれが演奏法を持つ完成した楽器として設計されている。最大ポリフォニーはアルゴリズムによって1〜12音、プリセットは96。ディスプレイは使わず、中央のLEDとセンサーで操作する。

### 3. FLUX

FLUXは静電容量式テルミンではなく、演奏者が持つ磁気弓と多極磁気センサーを使う。

右手の弓では、X座標が音程、Z座標が音量を担当する。弓を反転するとオクターブが変わり、左右の傾きは二つの独立したモジュレーションを扱う。左手の弓はX/Y/Zと磁極の反転を用い、最大12個の音色パラメーターを制御する。右手側を含めて合計16の音響制御へ演奏中に触れられる。

37音の位置目印、9オクターブの音域、最大37音響アルゴリズム、アルゴリズムにより1〜12音のポリフォニーを持つ。無量子化だけでなく量子化、スタッカート、ビブラート調整も用意されている。

### 4. LYRA-8

LYRA-8は8個の音源を、`12 / 34 / 56 / 78` の4ペアへ分け、さらに `1234 / 5678` の2群へまとめる樹状構造を持つ。普通の減算型VCOではなく、古い電子オルガンの発音器に近い。音源はオルガン的な動作とFM動作を持ち、各音源のエンベロープが減衰するとFMへの影響も減る。

HYPER LFOは二つのLFOの周波数を加算または乗算する。MOD DELAYは二本の低品位ディレイをクロスフィードバックし、各ディレイ時間を別々に変調できる。出力信号が自分のサンプルレートを変調する自己変調も持つ。ディストーションはディレイの後段に置かれている。

公式FAQでは、長いディレイ時間にした際のノイズが設計上の副作用として明記されている。ノイズ自体が目的なのではなく、通常範囲を越えたディレイ時間、帰還、LFO、自己変調による動作範囲の拡大と不可分になっている。

### 5. PULSAR-23

PULSAR-23は23個の独立モジュールを持つ半モジュラー式のドラムマシン。スタンドアロン、MIDI、CVを同時に組み合わせられる。4チャンネルはBass Drum、Bass/Percussion、Snare、Cymbals/Hi-Hat。

4個のルーパーが記録するのは音声ではなく発音イベントで、それぞれ個別にクロック可能。ADDは録音中ならオーバーダブ、再生中なら記録を変えずに生演奏を追加する。DELは録音中ならイベント消去、再生中なら記録を変えない一時ミュートとして働く。

マスタークロックと分周器はルーパーと共有される。公式インタラクティブ・マニュアルでは、分周出力が2、4、8、16、32、64、128分周に相当し、ルーパー全長を128ティックとして扱う構造が示されている。LRSTへ分周出力を接続してループを途中で再始動し、短い周期へ変形することもできる。

4個のエンベロープはサステインを生成でき、ドラム音源をノイズ／ドローン音源へ変える。LFOは0.1〜5000 Hz。SHAOSはシフトレジスターに基づく擬似ランダム信号を4出力する。FXはDSP全体のサンプルレートまでCV制御できる。

身体導電を使う抵抗センサーはオン／オフだけではない。圧力、接触面積、皮膚水分に反応する動的CVを生成する。

### 6. COSMOS

COSMOSは44.7秒の音声記憶を持つ。記録音を一定長で単純反復せず、異なる大きな素数を長さに持つ複数の遅延線、非同期LFO、ゆっくり変化するカオス信号によって再結合し続ける。

公式の説明では、通常のルーパーのような積層を可能にしつつ、露骨な反復を避けることが目的とされている。COSMOSのファームウェア更新履歴では、V1.0以降は稀な不具合と信頼性の改善で、音響設計と機能は変更していないとされる。

## 推論・仮説

以下は公式仕様そのものではなく、上記構造からの設計推論。

### Organismicの実装上の意味

SOMAのorganismicは「ランダム値を足すこと」ではない。

1. 少数の要素が互いを変調する。
2. 音声と制御信号を厳密に隔離しない。
3. 時間軸を一つのマスターグリッドへ完全には固定しない。
4. 操作者の身体を信号経路に含める。
5. 帰還はエフェクト量ではなく、発音状態そのものを変える。
6. 破綻を除去し尽くさず、演奏可能な境界として残す。

LYRA-8では音源、エンベロープ、ディレイ、歪みが循環的に影響する。PULSAR-23ではイベント、分周、擬似ランダム、身体CV、音声が同じパッチ網へ入る。COSMOSでは互いに一致しない時間軸が長期的な変化を生む。

### COSMOS型漂流記憶の試作モデル

単純な同一周期ループではなく、複数の遅延線を使う。

```
write(input)

for each memory line i:
    delayLength[i] = nearbyPrime(baseLength * ratio[i])
    drift[i]       = asyncLFO[i] + slowChaos[i]
    readPos[i]     = writePos - delayLength[i] + drift[i]
    tap[i]         = interpolate(memory[i], readPos[i])

output = dry + sum(tap[i] * gain[i])
feedbackBus = diffusion(matrix * taps)
write(feedbackBus + input)
```

実装時は次を制限する必要がある。

- driftの変化速度を十分遅くする。
- 読出し位置の変化は補間し、クリックを避ける。
- feedback matrixのスペクトル半径を1未満に抑える。
- DC除去、低域蓄積防止、ソフトリミッターを帰還内へ置く。
- 素数は魔法の音質要素ではなく、共通反復周期を遠ざける時間構造として使う。

### PULSAR型イベントルーパーの試作モデル

4音声トラックとは別に、ドラム専用のイベント循環を持つ。

```
Event {
    tick: 0..127
    voice: BD | BASS | SNARE | HH
    velocity: 0..1
    probability: 0..1
    microOffset: samples
}

ADD:
    REC  -> eventを現在tickへ追加
    PLAY -> 記録せず現在だけ発音

DEL:
    REC  -> 現在近傍のeventを削除
    PLAY -> 現在だけ発音を抑制

LRST:
    playhead = restartTick
```

SHAOSは各ステップを独立乱数にするのではなく、シフトレジスター由来の相関したビット列として使う。これにより直前の状態との関係を残した変化を作れる。

### LYRA型音源の試作モデル

8発振器をそのまま複製するより、まず4音源で相互作用を成立させる。

```
voice[i] = oscillator(freq[i], shape[i])
env[i]   = touchEnvelope(i)

fm[i] = sum(coupling[j][i] * voice[j] * env[j])
freq[i] *= exp2(fm[i] * fmDepth / 12)

hyperLFO = mode == SUM
    ? lfoA + lfoB
    : lfoA * lfoB
```

後段は二重ディレイのクロス帰還と自己変調を持たせる。ただしWeb Audio/iPhoneで遅延時間を直接激しく動かすとクリック、ピッチ跳躍、発散が起きるため、補間と帰還リミットが必要。

## Field Looperへ採用する点

### 高優先度

1. **COSMOS型の漂流記憶をマスター送信として追加**
   - 4つの通常ループは維持する。
   - 合成後の音を漂流記憶へ送る。
   - 通常ループの位置と内容は変えない。
   - 「ループが消える」のではなく、過去が異なる密度で戻る構造にする。

2. **PULSAR-23型の独立ドラム部**
   - 4音声トラックへドラムシーケンサーを埋め込まない。
   - ドラムはイベントを記録し、音声ループとは別の時間構造を持つ。
   - ADD／DELを押している間だけ介入できる直接演奏へする。
   - LRST相当の再始動で、ロール、周期短縮、戻しを作る。
   - 個別乱数ではなく相関するSHAOS型変化を使う。

3. **TERRA型のマクロ演奏入力**
   - 一つの接触で音量、明るさ、変調量を同時に変える。
   - 端末の傾きを任意の音響軸へ割り当てる。
   - 音響エンジンごとに操作の意味を固定し、パラメーター一覧を演奏者へ押しつけない。

### 中優先度

4. **LYRA-8型の相互変調音源**
   - 独立したテクスチャ音源として使う。
   - ルーパー全体の常時動作にはしない。
   - ランダム発振ではなく、音源間FM、エンベロープ連動、二重ディレイ帰還を核にする。

5. **FLUX型の連続ジェスチャー**
   - 磁気弓の複製ではなく、音程／音量／音色が一つの軌道から同時に変わる考え方だけ採る。
   - iPhoneではマルチタッチ、指速度、接触面積、ジャイロを入力にする。

## 採用しない点

- 5機種を一つの画面へ並べた巨大なSOMA模倣UI。
- 「organismic」をノイズ、ランダム、常時発振の言い換えとして使うこと。
- COSMOSを4トラックの明示的な録音／再生の代替にすること。
- PULSARの100以上のパッチ点をiPhone画面へ再現すること。
- FLUXの磁気弓を通常のXYパッドだけで再現したと主張すること。
- LYRAのハードウェア由来ノイズを、無関係なデジタルノイズ注入で模倣すること。
- 自動録音開始。録音は演奏者の操作で始める。

## 次の研究
