# 発音候補27件の消失原因を原音で検証

Metamorphoses の620.1–629.9秒を検証。音源を一度デコードし、同じサンプルから10秒と30秒の解析を行った。共通区間の正規化前の音量立ち上がり系列は差0だった。

99パーセンタイルによる正規化係数が0.02840185から0.10358765へ3.6472倍に変わっていた。短窓の音を変えず、この係数だけを長窓の値へ交換すると93候補が66候補へ減り、長窓の全候補時刻と完全一致した。消えた27件はすべて高さ閾値に届かなくなり、うち13件は突出度の閾値にも届かなかった。

従ってこの27件の窓長依存の消失は正規化係数の変化で説明できる。演奏の音数や休符の変化として解釈できない。27件が物理的な打撃であるかは別途未確定。

再現: リポジトリの research/music-analysis/calibrate_analyzer.py を source-main/research/music-analysis/ に配置し、音源をスクリプト記載のSHA256名で配置して python music-findings/onset_cause.py を実行。numpy/scipy/ffmpegが必要。音源はGitに含めない。

検証方法への反映: 異なる長さの窓でそれぞれ正規化した候補数を演奏密度として比較しない。原音の立ち上がり量と採用閾値を併記する。固定基準で一致させること自体を採譜の正解とはしない。
