# 発音境界の原音照合 — Metamorphoses 10:15–10:30
前回の16区間を発音16回とみなしていないか、原音に戻って検査した。音高継続区間をMIDIにすると、推定器が出力しない部分が休符になり、分断された部分で再発音する。しかし、それは原音の発音境界を測った結果ではない。

## 原音と候補譜の食い違い
4096窓での、候補の空白内の成分振幅中央値と直前・直後区間の振幅中央値の幾何平均との比:

長い空白の中央値の傾向は3窓で維持された。空白全体で音が一定に続くことは意味しない。たとえば後半には成分の大きな減衰がある。平均や中央値でそれを消さないため0.5秒ごとの値も保存した。
短い2つの空白は全ての窓の時間幅未満であり、消音か継続か、この帯域測定では判定できない。ゼロに近いdB差を継続の証明に使わない。

音楽上の解釈: Fに近い成分の強弱変化を含む区間を、音高推定器の出力の有無だけで短い音符・休符に切り刻んではいけない。音の存在、再発音、音量変調、余韻を分ける必要がある。別楽器の同音や倍音重なりも残る。

## 採譜データの実際の修正
pitch-presence-revision.jsonを作成。16区間について、観測された音高と区間は保持し、attack_time_s・release_time_s・instrumentをnullとした。statusはpitch_presence_only。
以前のMIDIは診断音生成用として保持し、演奏用採譜としての採用を止める。原音の休符や再発音が確認できていないからである。推定の空白を無条件で結んで長音へ変える処理も行っていない。

## 反復の追加確認
図上で周期的に見える振幅ピークを原音で確認した。最短間隔0.8秒、prominenceは同区間全体の最大振幅の15%で固定し、3窓を比較。
4096/8192窓では615–625秒に7ピーク、2048窓では9ピーク。長い2窓の間隔は約1.15–1.98秒と変動。見た目から「正確な3拍反復」と命名しない。これは音量のピーク時刻で、発音時刻でもない。

## 精度評価
今回改善したのは根拠のない休符・再発音を採譜から除外する扱い。実録音の正解率やタイミング精度が上がった数値として報告はできない。
発音境界の確定には、同じ音の再発音と音量変調を区別する証拠が必要。今回の帯域エネルギーだけで確定しない。
