# 消失した27候補の帯域別原音検証
原音 Metamorphoses 620–630秒。前回判明した窓長正規化による候補消失を、音源の局所変化で追跡した。

30–180Hz、180–1500Hz、1500–10000Hzの帯域を4次Butterworth・前後方向フィルタで測定。元のRMSフレーム先頭に512/44100秒を加えたフレーム中心を固定測定点とし、その前後10/20/40msの平均二乗振幅を比較。中心は実打撃時刻として確定したものではない。測定点を最良値に動かしていない。

暫定条件「左右それぞれが全3幅で3dB超上昇」を満たす5箇所:
|中心時刻 秒|帯域|前後20ms・左右エネルギー合計の上昇|
|---|---|---|
|621.8982|1500–10000Hz|6.73dB|
|623.4366|1500–10000Hz|13.70dB|
|625.7702|30–180Hz|6.70dB|
|626.1765|1500–10000Hz|12.15dB|
|627.7555|1500–10000Hz|5.23dB|

音楽研究上の判断: 全体の音量立ち上がりに単一閾値を適用すると、高域・低域の局所変化を落とす事例がこの録音で確認できた。これらを一律に休符や無打撃に置換すると、再構成で原音の変化を失うおそれがある。暫定的に帯域別の変化点として保持する。

残る22件はこの条件で不成立であり、誤検出と確定したわけではない。条件は物理的打撃の正解データで校正されていない。前後方向フィルタによる時間的にじみ、低音の周期、うなり、音量変調があるため、この5件もキック/ハイハット/タブラやJeff本人の操作へ帰属させない。強弱をMIDI velocityへ直接換算しない。
