## 観測できた事実

### 1. 原点は固定バンドよりサウンドシステムにある

Massive Attackの母体The Wild Bunchは、DJ、MC、歌手、グラフィティ作家が出入りするBristolのサウンドシステムだった。初期Massive Attackも、3D、Daddy G、Mushroomだけで完結せず、Tricky、Shara Nelson、Horace Andy、Jonny Dollarらの異なる役割をアルバム内部へ配置した。

`Blue Lines`の初期制作は、ターンテーブル、Ensoniq EPS、ドラムマシン、DJミキサーを中心とした比較的小規模な環境から始まったと報告されている。

### 2. `Mezzanine`は合意ではなく対立を含んで成立した

3Dはヒップホップ／ソウル中心の既存像を反復すると自分たちを閉じ込めると考え、ポストパンク、ギター、ノイズへ向かった。Mushroomは、よりソウルとヒップホップを保持したかったと述べている。

Neil Davidgeはメンバー間を移動しながら複数曲を同時に扱い、制作を接続した。制作後、Mushroomは離脱した。

### 3. 作曲、録音、編集、ミックスは分離されていない

`Angel`はミックス段階で新しいベースラインとリズムパターンが追加され、別の曲と言えるほど変化した。3Dは、素材を意味のある順序と文脈へ置く「編集」が制作を定義すると述べている。

### 4. 大量録音はそれ自体では価値にならなかった

`100th Window`初期制作では、ライブ・バンドのジャムを三台のPro Tools環境で約80時間収録した。最終的に使われたのは`What Your Soul Sings`のギターリフ一部だけで、残りは破棄された。

Davidgeの説明では、全員で鳴っている文脈では成立しても、個々のパートを核として取り出すと強度を失った。制作は、ひとつの音からパートを作り、小さな配置を経て次を積み上げる方法へ戻った。

### 5. 常時録音は「完成テイク」ではなく事故を捕捉するためだった

Massive Attackのスタジオでは、演奏者が録音開始を意識して身体を変えないよう、常時録音する運用が行われた。練習後に完成テイクを録るのではなく、探している途中で一度だけ発生する音を残すことが目的だった。

### 6. 音源の由来と処理後の役割を切断する

`Small Time Shot Away`では単純なJunoの一小節素材を速度、オクターブ、再編集で変形した。`Everywhen`ではキック、リムショット、ハイハットへディレイ、ドップラー処理、GRMフィルターを加え、ギターのようにも受け取られる旋律的な骨格を作ったとDavidgeが説明している。

### 7. `100th Window`で集団の中心は3D／Davidgeへ収縮した

Mushroom離脱とDaddy Gの一時離脱後、3Dの視覚的・抽象的な指示をDavidgeが具体的な音響へする二者関係が制作の中心になった。

### 8. `Heligoland`では外部の身体を再び多数導入した

Horace Andy、Tunde Adebimpe、Martina Topley-Bird、Hope Sandoval、Guy Garvey、Damon Albarnらの声と、Adrian Utley、John Baggott、Billy Fuller、Jerry Fuchsらの演奏を導入した。

これはThe Wild Bunchの地域共同体へ戻ることではなく、3DとDavidgeが曲ごとに異なる身体を選び、編集する共同体だった。

### 9. 2020年代には作品単位が音源の外へ広がった

`Eutopia`では音楽、政治的発話、字幕、生成映像を一作品として扱った。2026年のTom Waitsとの`Boots on the Ground`も、音源、映像、政治的文脈、流通方針、再生素材による物理媒体を一つの制作単位として提示している。

## 構造的解釈・仮説

以下は資料にそのまま書かれた事実ではなく、上記観測からの研究上の解釈である。

### A. 発明は「トリップホップ」ではなく選曲行為の内部化

Massive Attackはジャンル同士を滑らかに融合させたというより、サウンドシステムで異なるレコードと声を接続する行為を、一曲・一アルバムの内部へ移した。

統一性は固定メンバーや楽器編成ではなく、低域、速度、空間、声の距離、緊張状態によって作られる。

### B. 遅さは停止ではなく相反する力の同居

キック、ベース、打楽器、声、ディレイが完全に同じ時間重心を共有しない。前へ進む層と、その場へ拘束する層を同時に置くため、テンポが遅くても静止しない。

`Inertia Creeps`について3Dが語った「前へ押す動きと後ろへ引く動き」は、この構造を説明する有力な手掛かりである。

### C. `Angel`の展開は加算より包囲として読める

曲の変化は新しいコードやセクションの追加だけではなく、低域から高域まで占有される範囲が増え、逃げられる空白が減る過程として解釈できる。

Horace Andyの親密で甘い声を脅威の声へ直接変形するのではなく、その周囲の環境が声の意味を変える。

### D. `100th Window`の一貫性は同時に限界でもある

3D／Davidgeの二者関係は音響的一貫性を高めた一方、`Mezzanine`に存在した相反する美意識の摩擦を減らした可能性がある。Massive Attackの強度には、完成度だけでなく、異質な人間が完全には和解しないことも含まれる。

### E. 長期的な本体は編集主体である

Massive Attackは、レコードを選ぶサウンドシステム、サンプルを解体するスタジオ集団、人間や政治的言説まで選び直す制作母体へ変化した。

固有の音色より、異種の声・音・技術・媒体を選び、その違いを消さず一つの時間へ編集することが継続している。

## Live Canvasへ採用する点

### 1. Rolling Capture

直近15〜30秒の音声と演奏ジェスチャーを循環保持する。

保持候補:

- 音声
- 指の軌跡
- 接触面積
- 速度
- 同時タッチ間の距離
- 音響パラメータ変化

ただし自動ループ化しない。ユーザーの追加接触によって直前の身振りを選び、現在の指で変形・再演奏できる一時素材へする。

### 2. ループを状態系列へ変える

固定反復:

```text
A -> A -> A -> B
```

採用候補:

```text
A0 -> A1 -> A2 -> A3
```

同一素材を保持しながら、密度、重心、前景、時間幅、倍音、残響、ステレオ幅を不可逆に変える。

### 3. 音源カテゴリと演奏機能を切断する

- 打楽器を旋律へする
- 和音をリズムへする
- 声を環境音へする
- ノイズを拍の目印へする
- 残響を次の演奏を誘発する入力へ戻す

`ドラム／ベース／ボーカル／FX`という固定トラック分類より、現在の役割を身体操作で移動させる。

### 4. 四トラックを楽器名ではなく機能で分ける

| 層 | 役割 |
| --- | --- |
| 1 | 地面: キック、最低域、周期の基準 |
| 2 | 身体: パーカッション、揺れ、異なる周期 |
| 3 | 視点: 声、語り、断片、カメラ位置 |
| 4 | 環境: ギター、ノイズ、残響、帯域占有 |

これは確定UIではなく、Massive Attack研究からの設計候補である。

### 5. 編集を演奏中の操作にする

録音後に波形画面へ移動して切るのではなく、演奏中に次を行えるようにする。

- 直前の強い瞬間を掴む
- 残りを捨てる
- 掴んだ身振りの一部だけを再発生させる
- 別の役割へ変換する
- 元の演奏へ戻らず次の状態へ進む

## 採用しない点

1. 「暗いパッド＋遅いドラム」をMassive Attackプリセットとして追加しない。
2. 自動生成された変化を演奏者の判断の代わりにしない。
3. 常時録音を無制限保存にしない。短い循環バッファと明示的取得に限定する。
4. 80時間のジャムの事例を、素材量を増やせば質が上がるという根拠に使わない。
5. 音楽、政治、環境運用の結合を、製品へ自動的に採用済みとは扱わない。

## 失効した判断

- `Massive Attack = トリップホップの代表`だけで研究を閉じる見方は失効。
- `Mezzanine`の暗さを一枚岩の美学とする見方は失効。制作内部には明確な方向対立があった。
- `100th Window`以後は過去の反復にすぎないという見方は失効。制作主体、共同体、作品媒体の単位が変化している。
- `100th Window`と`Heligoland`はサンプルを一切使わない、という広すぎる表現は失効。借用録音を骨格にする方法から離れたことと、サンプル音源や音声編集の使用は区別する。

## 現在の判断

Massive AttackからLive Canvasへ移植する対象は音色ではない。

```text
常時捕捉する
-> 強い瞬間だけを選ぶ
-> 元の役割から音を外す
-> 直前の状態から次を発生させる
-> 異なる身体の時間を統一しすぎない
-> 編集を演奏中に行う
```

研究は`active`。製品採用、実装、実機検証は未実施。

### 横断後の修正仮説

Massive Attackの本体を「異種素材の編集主体」とした仮説は維持する。ただし、編集を一語でまとめると四つの時間責任が消える。

1. **Dub — 在／不在を決める。**  
   元素材を鳴らすか、空白へ退かせるか、過去のtailだけを残すかを演奏する。

2. **Portishead — 世代を変える。**  
   現在の演奏を捕捉し、媒体・摩耗・再録音を経た別時代の資料として戻す。

3. **Autechre — 次に可能な出来事を変える。**  
   同じ素材を反復しながら、履歴と他声部の状態によって次状態の範囲を更新する。

4. **Jeff Mills — 入口と出口を引き受ける。**  
   床を保ちながら素材の滞在時間を短い判断窓で決め、事故を次の構造へ変える。

この四つを合わせると、Live Canvasでいう「編集を演奏する」は次のように具体化できる。

```text
capture
-> choose presence
-> assign generation
-> alter next-state conditions
-> enter / stay / exit
-> preserve or rebuild the floor
```

### Live Canvasへ返す最小実験候補（未採用）

#### 実験A: PRESENCE / TAIL

一つの録音断片について、`dry presence`、`send`、`return tail`を別状態にする。目的はDub音色の再現ではなく、原音が消えた後も過去だけが独立して作用できるかの確認。

#### 実験B: GENERATION HANDOFF

直前の演奏をRolling Captureで掴み、一世代だけ帯域・速度・残響境界を変えて、元入力とは別の演奏対象へする。Portishead研究のself-sampleを、Massive Attackの「強い瞬間だけを選ぶ」判断へ接続する。

#### 実験C: STATE-BOUND MUTATION

`A0 -> A1 -> A2`の遷移を自動ランダム化せず、直前のgesture、別層の休止、最近の反復回数だけで候補範囲を変える。演奏者は方向を決め、システムは制約内の細部を返す。

#### 実験D: ENTRY / STAY / EXIT

素材の再生トグルではなく、入れる、滞在させる、抜くを分ける。床が`held | weakened | broken | rebuilt`のどこへ移ったかをPerformance Takeへ記録する。

四実験を一度に実装しない。最初はAまたはDの一つだけを既存4層のうち一層へ限定し、操作が止まったとき完成ループが無期限に代演しないことを評価する。

### 反証条件

次のいずれかが観察された場合、横断仮説を修正する。

- PRESENCE / TAIL分離が聴覚上の編成変化でなく、通常のsend effectとしてしか知覚されない。
- 世代加工が演奏の履歴を作らず、単なるlo-fi presetになる。
- 状態遷移が演奏者の方向選択より強くなり、自動作曲へ寄る。
- entry / stay / exit分離が即時判断を増やさず、操作負荷だけを増やす。
- 床の維持が常に安全側へ固定され、破断と再構築が演奏上の選択にならない。

### `Angel`の中心仮説を修正する

以前の仮説は「加算による包囲」だった。今回の資料を接続すると、検証対象は単純な音数増加では足りない。

`Angel`では、Horace Andyの歌唱を脅威的な声へ直接加工したのではなく、親密な歌唱の同一性をある程度保持したまま、低域、打楽器、ギター、残響、帯域占有が周囲の状況を変えた可能性がある。Del Naja自身の「Horace Andyをstrange spaceへ置いた」という説明は、この読みを支える。ただし、どの処理がどの時刻で意味を変えたかは音源取得後の検証事項である。

したがって、分析単位を次の四層にする。

| 層 | 保持／変化を見る対象 | 記録値 |
| --- | --- | --- |
| VOICE | 音高輪郭、発語、伸長、反復、前景距離 | phrase start/end、pitch contour、短時間ラウドネス、残響比 |
| FLOOR | bassとkickが作る周期・重量 | onset、sub-band envelope、周期候補、休止 |
| PRESSURE | drums / guitar / noiseによる包囲 | onset density、帯域占有、crest factor、歪み候補 |
| SPACE | dryとreturn、定位、奥行き | stereo width、残響尾、前景／後景の交代 |

中心仮説は次へ更新する。

```text
声の意味を直接書き換える
ではなく
声の同一性を残す
-> 周囲の床・圧力・空間を変える
-> 同じ親密さを脅威として再読させる
```

### EVENT / RELATION / TRANSITION記法

音源取得後は、感想文ではなく一事件一行で記録する。

```text
t_start
t_end
layer      VOICE | FLOOR | PRESSURE | SPACE
event      enter | exit | thicken | thin | widen | narrow | distort | return
evidence   DIRECT_AUDIO | MEASURED | CREDIT | INTERVIEW | INFERENCE
relation   voice-floor | floor-pressure | voice-space | pressure-space
state_from exposed | held | enclosed | saturated | released
state_to   exposed | held | enclosed | saturated | released
confidence high | medium | low
note
```

同じ音の追加でも、`VOICE`を覆うのか、`FLOOR`を維持するのか、`SPACE`を狭めるのかで別事件として扱う。

### `Angel (Angel Dust)`を対照群にする理由

Mad Professorによるremixは、単に別バージョンを増やす資料ではない。Dub研究の「原音の在／不在、投擲、帰還、空白」と、Massive Attack版の「周囲を変えて声を再文脈化する」を同じ素材系列で比較できる可能性がある。

比較時は次を固定する。

- vocal phraseの残存率
- dry vocal不在区間
- bass floorの連続性
- return tailの自律時間
- guitar / percussionのentry数
- 編成状態数
- 最大密度後に空白へ戻る経路
- 声の意味変化を、声処理と環境処理のどちらが担うか

Shazamがremixへ表示する`106 BPM`は外部メタデータとして保存するが、アルバム版とのテンポ一致や倍テンポ解釈は独自測定まで確定しない。

### Live Canvasへ返す一つの実験（未採用）

前回の四候補から、最初の検証対象を`VOICE / ENVIRONMENT REVERSAL`へ絞る。

1. 一つの声断片をRolling Captureする。
2. 声自体のpitch、timing、formantは固定する。
3. `FLOOR`、`PRESSURE`、`SPACE`だけを別々に演奏する。
4. 演奏者が「親密／脅威」のような意味ラベルを操作しない。
5. 聴取者が声の意味変化を感じた時刻と、環境層の操作ログを照合する。
6. 声そのものを加工した条件を対照として用意する。

目的は`Angel`風の音色を作ることではない。**素材を変えず、関係を変えることで意味が移動するか**を検証する。

### 反証条件

- 声を固定した条件では、環境層を変えても意味知覚が動かない。
- 意味変化が低域や空間でなく、歌詞理解または声自体の加工だけで説明される。
- `VOICE / FLOOR / PRESSURE / SPACE`の分離が聴取上識別できない。
- Shazamの認識集中区間が再取得時に大きく移動し、分析窓選択の補助にもならない。
- `Angel (Angel Dust)`との比較で、Dub操作より別ミックス／マスタリング差が支配的になる。
- Live Canvas上で三環境層の操作が演奏にならず、単なるmacro automationになる。
