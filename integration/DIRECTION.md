# プロジェクト方向

更新日: 2026-08-28

## 中心

このプロジェクトは、iPhoneを素材採取、4トラック録音、直接操作、演奏処理まで一続きにする個人用楽器を作る。

既存DAWの縮小版にも、調べた機材の機能を全部載せる箱にも、ユーザーの代わりに演奏を決める自動生成機にも寄せない。

## 現在固定する境界

1. **4トラック**
   - ループ／録音の中心は4トラック。
   - 個別トラックを保ったまま、合成結果を波形として直接触れる。
2. **録音は人間が開始する**
   - 自動録音開始を既定にしない。
   - 入力元、接続状態、録音中かどうかを画面上で判別できるようにする。
3. **iPhone固有の入力を活かす**
   - iPhoneマイクを妥協入力として扱わず、専用の入力段と音作りを研究する。
   - ヘッドホン接続時と本体マイク時の経路差を隠さない。
4. **KAOSSはマスター演奏層**
   - KAOSS系XY操作は、録音後の全体または選択レイヤーをリアルタイム処理する位置に置く。
   - 個別研究の機能を無制限にXYへ詰め込まない。
5. **ドラムは別系統**
   - IDM／Autechre方向のドラム研究を、4トラックルーパーへ無理に内蔵しない。
   - 将来接続できる独立演奏系として設計する。
6. **簡単さは機能削減ではなく演奏経路の短さで守る**
   - Koala Samplerより操作を複雑にしない。
   - 難しい操作、隠れたモード、同時押し前提を中心に置かない。
   - マルチタッチを妨げない。
7. **iPhoneの一画面を基準にする**
   - 横画面を主設計とする。
   - 縦画面は横の縮小ではなく、同じ機能へ届く専用配置を持つ。
   - 画面外に主要操作を追い出さない。
8. **研究対象は部品であり、製品の主人ではない**
   - Loopy Pro、RC-505mkII、KAOSS、Strymon、Dedalus、Teenage Engineering、Elektron、SOMAなどから、演奏に効く構造だけを採る。
   - 製品外観や操作体系を一台丸ごと模倣しない。

## 現在の信号構造

```text
iPhone入力
  -> 入力段／マイクプリ
  -> 4トラック録音
  -> 4トラック合成波形の直接操作
  -> KAOSS型マスター演奏処理
  -> 出力／Performance Take
```

ドラム演奏系はこの直列の内部に固定せず、同期または音声入力で接続する別系統とする。

## まだ固定しないもの

- AUv3化の最終構成
- Webアプリ版とネイティブiOS版の最終分担
- 各マスターFXの組合せとプリセット方式
- Performance Takeの最終UI
- SOMA由来の有機的揺らぎをどこまで自動化するか
- Elektron由来のシーケンス／音色選択の具体方式

これらは個別研究または試作の候補であり、実装されたという意味ではない。
